== Description ==

**AdLabeler - Automatically label your AdSense banners** is an intuitive plugin that automatically adds labels like "Ad" or "Advertising" to your AdSense banners, enhancing transparency and user experience. With this tool, you can easily improve the user experience on your website by providing clear indications of advertisements.

* Automatically adds labels to AdSense banners for enhanced transparency.
* Customize label text and placement to suit your website's design.
* Improve user experience by clearly indicating advertisements on your website.
* Lightweight and easy to set up.

== Installation ==
1. You can:
 * Upload folder `AdLabeler` to the `/wp-content/plugins/` directory via FTP.
 * Upload the zip archive via *Plugins -> Add New -> Upload* in the WordPress Admin Panel.
 * Search for **AdLabeler - Automatically label your AdSense banners** in the WordPress Plugin Directory and click on the *Install Now* button.
2. Activate the plugin through the *Plugins* menu in WordPress.
3. Configure the plugin settings under the *AdLabeler* menu in the WordPress Admin Panel.
4. You're all set! The plugin will now automatically add labels to your AdSense banners.

== Frequently Asked Questions ==
= Can I customize the label text? =
  Yes, you can customize the label text for both manual and automatic ads.
= Can I disable labeling for specific ads? =
  Yes, you can disable labeling for specific ads by configuring the plugin settings.
= Will this plugin slow down my website? =
  No, this plugin is lightweight and optimized for performance.
